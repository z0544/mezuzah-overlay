# שכבת מזוזה לקלף · Mezuzah Overlay

מדריך פריסה לסופר סת"ם ב-**Meta Quest 3S**. האפליקציה מציגה את המזוזה על הקלף האמיתי, דרך תצוגת המעבר (passthrough), בגודל שבוחרים, ועל השכבה הזו כותבים.

> **כלי עזר בלבד.** הוא לא מחליף שרטוט, כתיבה כסדרן או הגהה. לפני שימוש בפועל צריך אישור של פוסק.

## פתיחה בקסדה
1. ב-Quest פותחים את **Browser** ונכנסים לכתובת `https://z0544.github.io/mezuzah-overlay/`
2. בוחרים תבנית, גודל קלף ושוליים, ולוחצים **כניסה למצב AR**.
3. מכיילים: מכוונים את קצה הבקר ל-3 פינות של הקלף (ימין-עליון, שמאל-עליון, שמאל-תחתון), ובכל פינה לוחצים על ההדק.

מדריך מלא ופרוטוקול לבדיקת דיוק נמצאים בקובץ [`docs/INSTALL.md`](docs/INSTALL.md).

## תבניות
| תבנית | תיאור |
|---|---|
| **טקסט** | 22 שורות ו-713 אותיות, עם טביעת SHA-256 קבועה. ראשי השיטין לפי מחזור ויטרי, "על הארץ" בראש השיטה האחרונה. הרווח בין מילים הוא י', ושורות מתמלאות בהארכת ה ת ם ל, אבל אף פעם לא בשמות שאינם נמחקים. ע' ו-ד' רבתי אופציונליות |
| **רשת** | 22 קווי שרטוט, בלי טקסט |
| **תמונה** | סריקה של תיקון מוגה שלכם, עם טביעת SHA-256 |

מקורות הטקסט מתועדים בקובץ `src/data/mezuzah-text.json` ובתוך האפליקציה.

## פיתוח
```bash
npm install          # three, esbuild, iwer
npm run build        # מייצר index.html יחיד בתיקיית השורש (וגם עותק ב-dist/)
npm test             # Playwright + IWER (אמולטור WebXR של Meta)
```
- `src/app.js`: לוגיקה, רינדור הטקסט וה-WebXR
- `src/index.template.html`: ממשק המשתמש (עברית, RTL)
- `src/data/mezuzah-text.json`: הטקסט המאומת
- `src/fonts/`: הגופנים והרישיונות שלהם
- `CLAUDE.md`: כללי הפרויקט, ה-DoD והלקחים

הדף לא תלוי ברשת: אין CDN ואין שום fetch חיצוני. האפליקציה לא ניגשת למצלמה ולא שולחת נתונים.
